## The Problem

Computers need communication protocols and shared services to exchange information.

## The Challenge

Connect several computers to a private network and make a website or messaging app available to everyone on it.

1. Connect the computers using Ethernet or Wi-Fi.
2. Identify each computer's local IP address.
3. Run a small web server on a Raspberry Pi or Linux computer.
4. Open the local website from another computer.
5. Add a shared service, such as a message board, file library, or local DNS name.
6. Draw a network diagram and explain how each request reaches the server.

## Technologies

- Raspberry Pi or another Linux computer;
- Ethernet or Wi-Fi;
- HTTP, IP, and optional DNS.

## Final Goal

Demonstrate a private classroom network with its own website and at least one shared service.

## Resource

[Raspberry Pi Documentation](https://www.raspberrypi.com/documentation/)

> Keep the project on an isolated classroom network. Do not expose its services to the internet.
