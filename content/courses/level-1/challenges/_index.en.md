Now use everything you have learned: build a project and show it to the world.

## Ideas for Real Projects or Challenges

### 1. Astronomy

1. **Galaxy Detectives — Help Astronomers Classify Galaxies**
   - **Problem:** Astronomers need help identifying patterns and rare objects in enormous image datasets.
   - **Challenge:** Contribute to a real citizen-science project by classifying galaxies, then build a simple app that recognizes different galaxy types.
   - **Technologies:** Zooniverse, Scratch, Python (optional), image classification.
   - **Final Goal:** Create a galaxy classification app and contribute to real astronomical research.
   - **Resources:** [Zooniverse Astronomy](https://www.zooniverse.org/projects?discipline=astronomy)

2. **Solar System GPS — Find the Best Route Between Planets**
   - **Problem:** Spacecraft need to navigate between moving planets while minimizing travel time and fuel consumption.
   - **Challenge:** Create an interactive application where users choose a departure planet and destination. Develop algorithms to calculate possible trajectories, avoid obstacles, and optimize routes using simplified physics.
   - **Technologies:** Scratch, Python or JavaScript, geometry, pathfinding algorithms.
   - **Final Goal:** Build a playable space navigation simulator that compares different routes and their efficiency.
   - **Resources:** [NASA Eyes on the Solar System](https://science.nasa.gov/eyes/)

## 2. Communication and Meteorology

1. **LoRa — Build a Communication Network Without Internet**
   - **Problem:** In remote areas or during emergencies, traditional communication networks may be unavailable.
   - **Challenge:** Build a small wireless network using LoRa devices. Send messages between different locations, measure communication range, and experiment with relaying messages through intermediate devices.
   - **Technologies:** LoRa, Meshtastic, ESP32, basic networking.
   - **Final Goal:** Create a functional communication network between groups, without Wi-Fi or cellular connectivity.
   - **Resources:** [Meshtastic](https://meshtastic.org/)

2. **Air Quality Detectives — Contribute to Pollution Monitoring**
   - **Problem:** Air pollution affects our health, but air quality is not measured everywhere.
   - **Challenge:** Build an air quality monitoring station, collect measurements around the school, and investigate how pollution changes throughout the day. Contribute measurements to an open citizen-science network.
   - **Technologies:** ESP32, particulate matter sensors, Python or Scratch, data visualization.
   - **Final Goal:** Build a working air quality station, publish suitable environmental measurements, and create a dashboard showing pollution trends.
   - **Resources:** [Sensor.Community](https://sensor.community/en/)

## 3. Homelab and Infrastructure

1. **Our Own Internet — Build a Local School Network**
   - **Problem:** Computers need communication protocols and shared services to exchange information.
   - **Challenge:** Connect multiple computers to a private network, configure local addresses, and create a website or messaging application accessible only from that network.
   - **Technologies:** Raspberry Pi, Ethernet, Wi-Fi, Linux, HTTP, DNS.
   - **Final Goal:** Build a private classroom network with its own website and services.
   - **Resources:** [Raspberry Pi Documentation](https://www.raspberrypi.com/documentation/)
