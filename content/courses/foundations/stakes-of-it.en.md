## What Can We Do With a Computer?

Now that you understand the basic parts of a computer, the interesting part begins.

Computers are tools for creating things.

You could use one to:

- write a story;
- draw digital art;
- edit a video;
- Listen music;
- create a website;
- program a game;
- control a robot;
- build a weather station;
- create a home automation system;
- communicate with another computer;
- analyze information;

But to sumarize all this, computer do only 3 things:
- it store data
- it compute, (solve problem for you)
- it communicate

input -> compute -> output

## Mini Challenge

Look around you and find **five computers**.

Remember: they don't have to look like laptops.

For each one, try to identify:

1. What information does it receive as **input**?
2. What does it **process**?
3. What information does it **store**?
4. What **output** does it produce?

Example:

```text
Game console

Input: controller
Processing: runs the game
Storage: saves games
Output: image on TV + sound
```

Can you find a computer somewhere that another person might not immediately recognize as a computer?
