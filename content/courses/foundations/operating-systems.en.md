## Hardware + Software

Great!

Now we have built a computer.

We have a CPU.

We have RAM.

We have storage.

We have electricity.

We press the power button...

And...

Nothing useful happens.

Something is missing.

### Hardware

**Hardware** means the physical parts of the computer.

If you can touch it, it is probably hardware.

For example:

- CPU;
- motherboard;
- keyboard;
- screen;
- RAM;
- SSD.

### Software

**Software** means the instructions that tell the hardware what to do.

Examples include:

- games;
- web browsers;
- drawing programs;
- programming tools;
- music players.

Hardware without software does not know what useful job it should perform.

Software without hardware has nowhere to run.

They need each other.


## The Operating System

One very important piece of software is called the **Operating System**, or **OS**.

You may already know some operating systems:

- Windows;
- macOS;
- Linux;
- Android;
- iOS.

The operating system sits between your programs and the computer hardware.

For example, imagine that a game wants to play a sound.

Instead of the game needing to understand every possible type of speaker, it can ask the operating system:

```text
Game → Operating System → Sound Hardware
```

The OS helps manage:

- files;
- programs;
- memory;
- hardware;
- users;
- networks;
- security.

You could think of the operating system as the **manager of the computer**.

Or, if you prefer something more mysterious:

> The hardware is the body.  
> The operating system wakes it up. 👻
